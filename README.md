# StudyPlan

StudyPlan is a web application designed to help students organize assignments, manage their workload, and build personalized study schedules. Unlike traditional planners, StudyPlan is being built with the goal of creating an adaptive scheduling system that automatically adjusts a student's study plan as assignments are added, completed, or changed.

## Features (Current)

* Interactive monthly calendar
* Previous/next month navigation
* Automatic synchronization with the current month and year
* Responsive calendar layout
* Collapsible to-do sidebar
* Clean, modern interface built with HTML, CSS, and JavaScript

## Planned Features

* Dynamic assignment creation and editing
* Adaptive study schedule generation
* Priority-based task organization
* Automatic schedule adjustments when deadlines change
* User accounts and saved schedules
* AI-assisted study recommendations
* Progress tracking and productivity analytics
* Notification and reminder system

## Technologies

## Project Status

🚧 **Currently in active development**

The current version focuses on building the application's interface and calendar system before integrating backend functionality and adaptive scheduling algorithms.

## Vision

Most planners simply store assignments. StudyPlan aims to become an intelligent planning assistant that continuously reorganizes a student's workload based on due dates, available study time, priorities, and completed work. The goal is to reduce the time students spend planning so they can spend more time actually studying.
